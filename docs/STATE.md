## تصمیم‌های قطعی (تغییر فقط با تأیید مالک محصول)

- یک استقرار چند‌مستاجری؛ همه‌چیز با `tenant_id`؛ قابل جداسازی برای مشتری بزرگ.
- TypeScript مونوریپو (pnpm workspaces): Next.js 16، grammY (تلگرام و بله با یک کد)، **SQLite روی `@libsql/client`** + Drizzle، Hono، pino، vitest، Playwright (یک سناریو).
- هویت مشتری در وب: نام + موبایل بدون OTP (+ قوانین ضد سوءاستفاده). OTP فلگ آینده.
- زمان‌بندی: ساعت کاری هفتگی + مدت خدمت ⇒ اسلات خودکار؛ سوئیچ به اسلات دستی (`manual_slots`).
- پرداخت: فقط کارت‌به‌کارت، رسید عکس، تأیید دستی.
- سه قالب سایت قابل تعویض توسط آرایشگر: night-gold، light-editorial، bold-modern.
- ویزارد آنبوردینگ کامل با پیش‌نمایش زنده + CLI معادل.
- **هیچ LLM‌ای در محصول** — نه OpenRouter، نه API مستقیم. متن هر سایت را مالک با Claude Code می‌نویسد (CLAUDE.md بند ۱۰، تصمیم ۱۴۰۵/۰۶/۱۶).
- **هاستینگ: سرور مشترک + pm2**، نه Docker. پورت وب `127.0.0.1:8800`؛ هیچ پورتی روی اینترنت باز نمی‌شود؛ دسترسی از تونل نام‌دار کلادفلر.
- ادمین‌های پلتفرم **داده‌اند نه پیکربندی**: سه راه افزودن/حذف، هیچ‌کدام دیپلوی نمی‌خواهد (CLAUDE.md بند ۶).

## چیزهایی که از مالک محصول لازم است

- [ ] **`VPS_SSH_KEY` با همان کلید مونوریپو عوض شود** — تنها مسدودکننده. کلید فعلی سالم و کامل است (`Ops → ssh-check` ثابت کرد: RSA‑2048، بدون رمز) ولی سرور آن را نمی‌شناسد: `Permission denied (publickey)`. تا آن موقع نه `Ops → status` ممکن است و نه ساخت `deploy.yml` بی‌خطر — چون مرج به `main` روی سروری می‌نشیند که محصولات درآمدزای دیگری دارد و اول باید تصادم نام اپ و پورت رد شود.
- [ ] توکن واقعی ربات تلگرام و بله (`ARAYESHGAR_DEMO_BOT_TOKEN` و `ARAYESHGAR_DEMO_BALE_TOKEN`) — کد آماده است، فقط پروب زنده‌ی بله مانده.
- [ ] راه‌اندازی یک‌باره‌ی دامنه‌ی رایگان `dpdns.org` + تونل کلادفلر → `CLOUDFLARE_TUNNEL_TOKEN` (راهنمای قدم‌به‌قدم در `docs/RESEARCH.md`).
- [ ] **تست لینک دمو با سیم‌کارت واقعی ایرانی روی دیتای موبایل** — هیچ تحقیقی جای این را نمی‌گیرد.

- [ ] ردیف رجیستری داشبورد در ریپوی مونوریپو (آن ریپو در دسترس این سشن نیست).

## سؤالات باز / پیشنهادهای تأییدنشده

- لیست انتظار و «رزرو مجدد یک‌کلیکی» — بعد از MVP.
- پیشوند مبلغ یکتا برای تطبیق رسید — پیشنهاد.
- تعیین رمز وب برای ادمینی که با آی‌دی عددی اضافه شده (الان `password_hash` خالی دارد و فقط در ربات کار می‌کند) — پیشنهاد، بیرون از دامنه‌ی بند ۷-۸.
- جدول `users`ِ قرارداد بند ۹ب با جدول `users` خودمان تصادم اسمی دارد؛ تا حل نشود صفحه‌های قیف/کوهورت/مالی داشبورد این پروژه را نشان نمی‌دهند (بی‌خطر).
